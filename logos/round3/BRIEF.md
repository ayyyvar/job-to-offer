# job-to-offer icon — round 3 brief
App: job-to-offer, iOS. Shares a job posting, checks in ~10 s if you can legally take it (visa, language, location), tracks applications, preps interviews. Users: CIS job seekers moving abroad.
Themes the user wants: path/journey, interview, job search.
App visual world: passport control (security-paper, entry stamps). Palette: paper #F3F5F4, ink #1E2622, green #2F6F5E, violet #5B3FA8, amber #E0A23B / #A86300.
User feedback so far:
- Concepts 1-4 (stamp check, magnifier passport, stamped document, three rings): "not great".
- Concepts 5-8 (road to pin, speech bubbles, briefcase+lens, path to door): "not great".
- Concepts 9-13: picked 11 (paper S-road with dashed centerline on green, violet start dot, amber end dot).
- Road writing "work" / "job" in one line: "text is illegible".
- Single road "j" (iteration-3): "doesn't fit".
Renders: logos/renders/*.png (512 px). SVG sources in logos/concepts and logos/iterations.
